# Build Note / Nota de compilación

## English

> **Note:** Before compiling the project, you must download the Vosk `.so` library and place it in this directory.

The [libvosk.so](https://github.com/alphacep/vosk-api/releases/download/v0.3.45/vosk-linux-x86_64-0.3.45.zip) file is required for the project to compile and run correctly.

## Español

> **Nota:** Antes de compilar el proyecto, debes descargar la biblioteca `.so` de Vosk y colocarla en este directorio.

El archivo [libvosk.so](https://github.com/alphacep/vosk-api/releases/download/v0.3.45/vosk-linux-x86_64-0.3.45.zip) es necesario para que el proyecto pueda compilarse y ejecutarse correctamente.
